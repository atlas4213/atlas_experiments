This pipeline was run using the files in this folder on uab's HPC. The steps that were run will be listed in order along with the commands used to run them. 


1. Trimming(Trim_Galore_/0.4.4-foss-02016b
trim_galore  --phred33 --nextera --paired <file1> <file2> -o <outputfile>

2. alignment to m10 (STAR/2.5.2a-foss-2016a) with Encode options
STAR  -- runThreadN 10  -- genomeDir <star directory> \ 
--outFilterMultimapNmax 20  --alignSJoverhangMin 8  -- alignSJDBoverhangMin 1 \
--outFilterMismatchNmax 999  --alignIntronMin 20  --alignIntronMax 1000000  \
--alignMatesGapMax 1000000  --readFilesIn \
<trimmed file 1> <trimmed file 2> --outFileNamePrefix <output file prefix>

3. Counting aligned reads (HTSeq/0.6.1p1-foss-2016b-Python-2.7.12)
Htseq-count -s no -a 10 <aligned SAM file> <mm10 GTF file> > <outputfile>

4. Exclude genes that are low expressers: keep if >1 cpm for at least 3/12 samples

5. GLM (unpaired) using edgeR, look at all contrasts between adults and infants:  KOd4 vs WTd4, KOd6 vs WTd6, KOd4 vs KOd6, WTd4 vs WTd6 (based on genes retained in step 4)
