Design a SQL database schema based on the data output from part 1. Write a SQL query that retrieves the following:
1. HGNC ID and disease connection

Query :

SELECT 
    h.gene_name,
    d.disease_name
FROM Hgnc_genes h
JOIN OSL_diseases d
    ON h.omim_id = d.omim_id
JOIN ensembl_genes_19 e
    ON h.ensembl_id = e.ensembl_id;

2. HGNC Gene Name and any gene name aliases parsed

SELECT
    h.gene_name,
    TRIM(alias.value) AS alias
FROM Hgnc_genes h,
JSON_TABLE(
    CONCAT(
        '["',
        REPLACE(TRIM(BOTH '[]' FROM h.gene_aliases), ', ', '","'),
        '"]'
    ),
    "$[*]" COLUMNS (
        value VARCHAR(100) PATH "$"
    )
) AS alias
ORDER BY h.gene_name, alias.value;
